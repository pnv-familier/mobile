# Familier Agent & UI Guidelines

This directory contains the single source of truth for UI design rules, refactor master plans, and skills used for agent-assisted and human development on the Familier mobile application.

## Contents

- [**`UI_DESIGN_SYSTEM_RULES.md`**](./UI_DESIGN_SYSTEM_RULES.md): The mandatory UI design system rules, design tokens, safe-area practices, and component usage guide.
- [**`familier_mobile_ui_refactor_master_plan.md`**](./familier_mobile_ui_refactor_master_plan.md): The complete 4-phase refactoring plan with screen inventories, decision logs, and quality gates.
- [**`skills/`**](./skills/): Specialized agent runbooks and skill definitions.
